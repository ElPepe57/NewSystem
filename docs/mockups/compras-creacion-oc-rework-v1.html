Lente 2 en detalle · qué sale del helper y cómo se rotula
El semáforo (crudo-vs-crudo) vs el margen (landed) rotulados distinto · la cobertura honesta ("sin referencia" / "—") · el snapshot → "¿la compra acertó?".
SEAM-A · dos lentes, dos bases
Semáforo · CRUDO vs CRUDO

Compara lo que negociás (costo crudo USD) contra tu base unificada = promedio histórico crudo. deltaPct = (costo − base) / base × 100. Responde: ¿estoy negociando bien?

Margen / CTRU · LANDED

Usa el costo aterrizado = (costo + cargos prorrateados) × tc. Margen vs PVP efectivo. Responde: ¿esto deja plata al venderlo?

Nunca se mezclan: el delta del semáforo NO incluye cargos (es negociación pura) · el margen SÍ (es costo real). Por eso se rotulan distinto en toda la UI.
Cobertura honesta · qué muestra cuando NO hay dato
historico
hay promedio propio → "vs tu histórico" + deltaPct real.
mercado
no hay histórico pero sí mejor proveedor investigado → "vs mercado" + deltaPct.
ninguna
no hay base → "Sin referencia" · deltaPct = null · veredicto = sin_referencia · se muestra "—", no un número inventado.
El score también re-normaliza por los factores con datos: si falta margen o histórico, no se penaliza por lo ausente — y si no hay nada, score = 0 → "Sin datos suficientes".
