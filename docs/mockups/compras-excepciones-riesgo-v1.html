Modal · Marcar envío perdido total (C2)
FormModalV2 · typed-confirm destructivo · el estado perdida_total existe sin setter · dispara reclamo + libera reservas + reconoce la pérdida
Requiere marcarEnvioPerdidoTotal(envioId, motivo) — el valor EstadoEnvio = 'perdida_total' ya está declarado en envio.types.ts pero ningún setter lo escribe hoy. El nuevo setter: (1) transiciona el envío a perdida_total · (2) abre un reclamo al transportista/proveedor · (3) libera las reservas de las unidades (punto único de liberación) · (4) reconoce la pérdida operativa.

6
Estados · empty + loading + error
Empty = buena señal (no es vacío "frío") · loading = skeleton del radar + incidencias · error = retry sobre las 3 fuentes async (radar helper · incidenciaOC.listAll · reclamos)
La tab depende de 3 queries async — radar helper (envíos en vuelo), incidenciaOC.listAll y reclamos (IncidenciaEnvio). Si cualquiera falla, se muestra el error state con retry (no un vacío silencioso que se confunda con "Todo en orden"). El retry re-dispara cargarDatos() de las 3 fuentes.
