Auditoría Capa ①

Lo que el sistema YA tiene en identidad & seguridad

Sólido (verificado)
  • Login Firebase Auth + UserProfile en Firestore
  • Multi-rol (9 roles) + 30 permisos granulares + overrides por usuario
  • Ciclo de vida: invitación → aprobación → suspensión → archivado + self-signup
  • Defense-in-depth: permisos UI + reglas Firestore (blacklist de campos sensibles)
  • Guard de cruce de identidad + auditoría login/logout + tracking de sesiones
  • Canon "admin ve todo" (admin = Object.values(PERMISOS))
Lo que falta para el norte
  • Roles externos: cliente · proveedor · transportista
  • Vínculo UserProfile ↔ ficha de dominio (hoy solo entidadMaestroRef para externos)
  • Aislamiento de datos por contraparte (un cliente solo ve lo suyo)
  • Portales acotados (los permisos hoy asumen acceso interno al ERP)
→ esto entra en juego al construir los logins externos · con security-guardian + legal-compliance.
